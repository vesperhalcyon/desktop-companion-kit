# Contributing

Keep changes small, testable, and privacy-preserving.

1. Fork the repository and create a focused branch.
2. Run `npm install`, `npm test`, and `npm run check`.
3. Add tests for new parsing, persistence, profile, or inbox behavior.
4. Do not commit private character profiles, private artwork, browser content, credentials, or generated application bundles.
5. Keep Page sight opt-in and local. Any network-backed personality adapter must be an explicit separate feature with visible controls and documentation.

Bug reports should include macOS version, browser, app version, exact reproduction steps, and sanitized logs. Never attach private page content.
