# Character asset

Place a transparent PNG or SVG in this directory and set its filename in `config/character.json`.

The renderer fits the image inside a 224 by 318 pixel stage without stretching it. A square PNG around 1024 pixels with generous transparent margins works well. The included `mascot.svg` is a neutral redistributable placeholder.

Private character assets belong in ignored files and should only be distributed when you hold the necessary rights.
